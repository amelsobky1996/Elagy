# علاجي — Elagy

تطبيق تذكير بمواعيد الأدوية لكل أفراد البيت، مبني بـ **Flutter Web** ويشتغل كتطبيق موبايل (PWA).

- إضافة أكتر من شخص، ولكل شخص أدويته
- اسم الدوا، النوع، الجرعة، المواعيد (أكتر من ميعاد في اليوم) وعدد الأيام
- إشعار مع كل جرعة، ومع آخر جرعة بيقول إنها **آخر جرعة**، وبعد ما الأيام تخلص التذكيرات بتقف لوحدها
- متابعة الجرعات اليومية (اتاخدت / فاتت / جاية) وتقدّم كل كورس
- سبلاش سكرين متحركة ~4 ثواني

## التشغيل
```bash
flutter pub get
flutter run -d chrome
```

## النشر
Vercel بيشغّل `build.sh` (بينزّل Flutter ويعمل `flutter build web`) وبينشر `build/web`.
